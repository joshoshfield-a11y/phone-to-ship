Watch the loop run before you buy it

No download, no sign-up. Five steps, each one a real command and its real output from a run of Phone-to-Ship on the included demo app. Click through it.

run 20261107-074509-ded5 23 files · 34,670 bytes 0 fails ended verdict-ship

Every line of output below is copied verbatim from that run — nothing invented, nothing tidied. The run happened in a scratch folder on this machine, so the paths in the output point there; on your phone they would point at your project instead. The demo app is the included demo-good tree: a small playable web tree, not a shipped game.

1. Brief it — scaffold the project

A short brief becomes a project shell: the brief itself, shipping checklists, release notes, and the phone-verdict sheet.

Termux — pts
$ pts new --name "Demo Game" --out ./demo-game --target web scaffolded Demo Game -> demo-game (targets: web) $ cp -r fixtures/demo-good/. ./demo-game/

What just happened: pts new scaffolded the project. The demo app itself — the included demo-good tree, 8 files — was then dropped into the new project. That is the "put your built web tree in" step. The copy printed nothing; cp is quiet when it works.

Step 1 of 5

2. Check it — the readiness gate

Before anything runs, the gate looks the tree over: required files, JS syntax, leaked files, credential-shaped values, file count, bytes, hashes.

Termux — pts
$ pts check --tree ./demo-game { "tree": "/tmp/pts-demo-scratch/demo-game", "files": 23, "bytes": 34670, "sha256_index": "83f14ed8f547298a7808974b6ec5f96de4cba589370d270b4be94e43378253f2", "fails": [], "warnings": [] } FAIL: 0 WARN: 0

What just happened: the gate counted the tree (23 files, 34,670 bytes), hashed it, and found nothing wrong — zero fails, zero warnings. A missing file, a JS syntax error, or a leaked file would have shown up here by name, and the loop would have stopped.

Step 2 of 5

3. Run the loop — build, test, diagnose, package

One command runs the whole loop against the brief: plan, build, test, diagnose, repair what it safely can, package — then stop and wait.

Termux — pts
$ pts orchestrate --tree ./demo-game --brief fixtures/demo-brief.md build: inventory only, 23 files in tree, nothing fabricated packaged v3.3.0: 23 files, 34670 bytes at /tmp/pts-demo-scratch/demo-game/.pts/staged/20261107-074509-ded5 run 20261107-074509-ded5: awaiting-approval staged package: /tmp/pts-demo-scratch/demo-game/.pts/staged/20261107-074509-ded5 pts verdict --tree /tmp/pts-demo-scratch/demo-game --run 20261107-074509-ded5 --decision ship|fix|hold --note "..."

What just happened: the loop inventoried the tree, tested it, and staged a package — then stopped at awaiting-approval. Note the first line: the build step only inventories what is already there, it fabricates nothing. The run waits here until a human decides.

Step 3 of 5

4. Package it — a clean deliverable

The same packaging, on its own: a staged deliverable with a manifest and a phone checklist, ready to take to a phone.

Termux — pts
$ pts package --tree ./demo-game --out ./demo-game-pkg --version v3.3.0 packaged v3.3.0: 23 files, 34670 bytes at /tmp/pts-demo-scratch/demo-game-pkg

What just happened: a standalone package, 23 files and 34,670 bytes, with a MANIFEST.json and a phone checklist inside. The orchestrate step in step 3 already staged one; this is the same packaging run on its own, so you can re-package without re-running the loop.

Step 4 of 5

5. You decide — the verdict is yours

The run has been waiting at awaiting-approval since step 3. Ship, fix, or hold — the call is a human's, and it is recorded, not acted on by the tool.

Termux — pts
$ pts verdict --tree ./demo-game --run 20261107-074509-ded5 --decision ship --note "demo run: played it, ships" run 20261107-074509-ded5: verdict recorded: ship — demo run: played it, ships verdict records a human decision only; nothing was published, pushed, or shipped.

What just happened: ship was recorded on run 20261107-074509-ded5, and the run's status became verdict-ship. The tool published, pushed, and shipped nothing — a verdict records a decision only. A second verdict on this run would be refused.
